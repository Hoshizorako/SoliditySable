# SoliditySable

SoliditySable facilitates high-performance, real-time data processing via a distributed, scalable compute cluster architecture.

SoliditySable is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SoliditySable.git`
2. `cd SoliditySable`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
